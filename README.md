# Job App

A simple mobile app design challenge showcasing the landing page for a job application app. The app features scrollable job recommendation cards, allowing users to select a job to view detailed information, including required

## Technologies
 - Flutter(Dart)
## How to Run This Project Locally
1. Clone the repository: `https://github.com/oliviertech212/job-app`
2. Change directory: ` cd job_app`
3. Install dependencies  `flutter pub get`
4. connect emulator 
5. the after connecting run `flutter run`
